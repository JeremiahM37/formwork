Welcome to formwork

formwork fills job applications from a profile you own. It reads whatever form is in front of it, decides each answer, and shows you everything before a single field is touched.

Nothing here leaves your browser. There is no formwork account, no server and no telemetry. Your name, email, phone and address are filled directly from this profile and are never included in a request to any AI model — including your own.

This takes about three minutes. Every step can be skipped and changed later.

Who you are

The contact details every application asks for.

Where you live

Applicant tracking systems split this into separate boxes and reject a combined value, so each part is stored on its own.

Links

Optional. Left blank, those fields are simply skipped.

Work eligibility

Legal attestations. formwork answers these only from what you set here — a model is never allowed to guess them, however the question is worded.

Voluntary disclosures

Employers ask these for equal-opportunity reporting and every one is optional. They matter here for a specific reason: without an answer to pin to, a language model will invent one from your name. These are pinned to exactly what you choose, and "Prefer not to say" is a real answer that gets filled as such.

Your résumé

Attached automatically to upload fields. Stored in this browser, never uploaded anywhere except the application you are filling.

Already have a LaTeX résumé? python3 tools/parse_resume.py resume.tex -o profile.json builds the whole profile from it — paste the result in Settings afterwards.

About you

Used only when drafting open-ended answers — "why do you want to work here", "tell us about a project". Write what you would say out loud: what you build, what you care about, what you want next. The more specific this is, the less generic the drafts read.

Drafts always land in a review panel for approval before anything is filled.

Account credentials

Workday, iCIMS and SmartRecruiters make you register before you can apply. formwork fills those signup and login forms from the values below.

Use a password unique to job applications. This is stored unencrypted in extension storage, the same as a browser password manager's autofill. It is never included in any model request — a password field is filled only from here, and any value a model proposes for one is discarded.

Drafting model

Only used for open-ended written answers. Everything factual — your details, eligibility, disclosures — is filled from your profile without a model involved, so formwork still works with this left unconfigured.

Ollama rejects cross-origin requests by default. Start it with OLLAMA_ORIGINS='chrome-extension://*' or these calls will fail.

You're set up

To fill an application:

  • Open the posting. On a known applicant tracking system the panel appears by itself.
  • Anywhere else, click the formwork toolbar icon to bring it up.
  • Press Fill this form, read what it proposes, then approve.
formwork never presses submit. The final send is always yours.

Anything here can be changed later in Settings, where the full profile is also editable as JSON.
