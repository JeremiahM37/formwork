formwork

Everything here stays in this browser. Your contact details are never sent to a model — they are filled directly from the profile below.

Profile

Generate with python3 tools/parse_resume.py resume.tex -o profile.json, then paste it here.

Documents

Attached automatically to matching upload fields. Stored in this browser only.

About you

Free-text notes used only when drafting open-ended answers — passions, hobbies, what you want in a role. The more specific this is, the less generic the drafts read.

Account credentials

Some systems (Workday, iCIMS, SmartRecruiters) make you register before you can apply. formwork fills those signup and login forms from the values below — they are never included in any model request. Stored unencrypted in this browser's extension storage, so use a password unique to job applications, not one you reuse.

Model

Uses Ollama's native /api/chat. Do not point the OpenAI-compatible option at Ollama's /v1 instead — that shim cannot disable reasoning, which measured 5× slower and mapped a fraction of the fields.

Ollama rejects cross-origin requests by default. Start it with OLLAMA_ORIGINS='chrome-extension://*' or the extension's calls will fail.
